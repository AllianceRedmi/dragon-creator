# Dragon Creator

This is a text-based Dragon Creator program written in Python 3. It allows users to create their own unique dragons by selecting various attributes.

## Features

- **Dragon Type:** Choose from various types (e.g., Fire, Ice, Shadow, Water).
- **Color:** Select the dragon's color.
- **Element:** Assign an element (e.g., Fire, Ice, Lightning, Poison, Darkness).
- **Wings:** Customize wing type (e.g., Large, Small, Webbed, Feathered).
- **Tail:** Configure tail type (e.g., Long, Short, Spiked, Flaming).
- **Size:** Determine the dragon's size (e.g., Small, Medium, Large, Colossal).
- **Name:** Give your dragon a unique name.
- **Dragon Card:** View a summary of your created dragon.
- **Save Dragon:** Save your dragon's details to a text file.

## How to Run

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/YOUR_USERNAME/dragon-creator.git
    ```
2.  **Navigate to the project directory:**
    ```bash
    cd dragon-creator
    ```
3.  **Run the program:**
    ```bash
    python3 main.py
    ```

Follow the on-screen prompts to create your dragon!
